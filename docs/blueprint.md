# **App Name**: Legacy AI

## Core Features:

- Intelligent Native Automation: Utilizes Gemini-2.5-flash as a tool to reason and execute native device functions including calling contacts, controlling music playback, and managing calendar schedules via function calling.
- Luminescent Fluid Morphing Visualizer: A centered liquid blob interface driven by CustomPainter and sine/cosine wave offsets to visualize processing states in real-time.
- Inverted Glassmorphic History Stack: A conversational layout architecture using BackdropFilter blur where newer messages are wider at the top and older logs scale down horizontally in a pyramid style.
- Proactive Inactivity Engagement Engine: A background service powered by workmanager that tracks interaction timestamps and triggers a local notification after 5 hours of inactivity.
- Hands-Free Continuous Voice Loop: An always-on voice interface designed to feel like a continuous phone call, utilizing the LLM as a tool to intelligently transition between real-time speech recognition, cognitive processing, and natural vocal synthesis.
- Cloud-Synced Context Persistence: Maintains user interaction history and session states across devices using a secure cloud database for long-term context memory.
- Bottom-Anchored Omni-Input Controller: A sleek, manual override text entry field positioned at the absolute bottom margin for non-voice commands.

## Style Guidelines:

- Deep Digital Void background using #100b14 near-black violet and #9d4edd electric purple as the primary brand color.
- High-contrast accent highlights using #b3b3ff lavender blue for active UI elements and borders.
- Headlines utilize 'Space Grotesk' for a geometric, tech-centric appearance.
- Body text uses 'Inter' sans-serif for optimal readability within dense conversation stacks.
- Inverted pyramid hierarchy for conversation cards, anchored beneath a central hero animation workspace.
- Physics-based liquid distortion for the central blob visualizer, pulsing in direct synchronization with audio amplitude levels.
- Thin-weight, neon-traced iconography represent native functions like music and calendar management.
- A 3-second ambient chime sound plays upon application launch to signal the initialization of the Legacy AI environment.
