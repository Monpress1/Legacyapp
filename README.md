# Legacy AI - Smart Core

Advanced AI companion for Eli Monpress (Agbolahan).

## Deployment Instructions (Vercel)

If the internal publish feature is unavailable, follow these 3 steps to get Legacy AI on your phone:

1. **GitHub Setup:** Create a new repository on GitHub (e.g., "legacy-ai").
2. **Push Code:** Copy the files from this project into a folder on your computer, initialize a git repo (`git init`), and push it to your GitHub.
3. **Vercel Connect:** Go to [Vercel](https://vercel.com), click "Add New Project," and select your "legacy-ai" repo. It will deploy automatically.

## Mobile Installation (Native Experience)

Once your Vercel URL is live:
1. Open the URL on your phone's browser (Safari/Chrome).
2. Tap **Share** (iOS) or **Menu** (Android).
3. Select **"Add to Home Screen"**.
4. The app will now launch as a full-screen native app without browser bars.
